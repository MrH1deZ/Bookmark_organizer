## 📞 Getting Help

### Documentation Not Helping?

1. **Check the Troubleshooting sections:**
   - [Setup Guide - Troubleshooting](./SETUP.md#troubleshooting)
   - [Technical Docs - Common Issues](./TECHNICAL.md#common-issues--solutions)

2. **Search for your issue:**
   - Use Ctrl+F to search within documentation
   - Check multiple documents

3. **Still stuck?**
   - Open an issue on GitHub
   - Include:
     - Browser and version
     - Extension version (v2.0.0)
     - Steps to reproduce
     - Error messages
     - Screenshots if applicable
