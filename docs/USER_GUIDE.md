# 🚀 Quick Start Guide - Version 2.0

Welcome to Smart Bookmark Organizer 2.0! Here's how to use all the new features.

## 🎯 Basic Workflow

### 1. Save a Bookmark
- **Right-click** any link → "Save Link as Bookmark"
- Or use **Ctrl+Shift+S** (customizable)

### 2. Open the Organizer
- Click the extension icon
- Or press **Ctrl+Shift+B**

### 3. Find Your Bookmarks
- **Search** by name, domain, tags, or notes
- **Filter** by file type or folder
- **Sort** by date, name, usage, or domain

## ✨ New Features Guide

### 🏷️ Working with Tags

**Add Tags to a Bookmark:**
1. Click the **✏️ Edit** button on any bookmark
2. Type a tag in the "Tags" field
3. Press **Enter** to add
4. See tag suggestions as you type!

**Filter by Tags:**
- Click any tag on a bookmark to filter by that tag
- Multiple tags = show bookmarks with ALL those tags
- Click "Clear" to remove tag filters

**View Popular Tags:**
- Click **📊 Stats** button
- Scroll to "Popular Tags" section

### 📁 Using Folders

**Organize into Folders:**
1. Click **✏️ Edit** on a bookmark
2. Type a folder name (e.g., "Work", "Personal")
3. See suggestions from existing folders
4. Click **Save**

**Filter by Folder:**
- Use the folder dropdown in the controls
- Select a folder to show only those bookmarks

**Bulk Folder Assignment:**
1. Click **☑️ Bulk** to enable bulk mode
2. Select multiple bookmarks
3. Click **Set Folder**
4. Enter folder name

### ⭐ Favorites

**Star Important Bookmarks:**
- Hover over any bookmark
- Click the **⭐** star icon
- It turns gold when favorited!

**View Only Favorites:**
1. Click **🔍** (advanced search button)
2. Check **"Favorites Only ⭐"**

### 📦 Bulk Operations

**Activate Bulk Mode:**
1. Click **☑️ Bulk** button
2. Checkboxes appear on all bookmarks

**Operations You Can Do:**
- **Select All** - Select every visible bookmark
- **Deselect All** - Clear selection
- **Delete Selected** - Remove multiple at once
- **Add Tag** - Tag multiple bookmarks
- **Set Folder** - Move multiple to a folder
- **Export Selected** - Save only selected ones

**Tip**: Use filters FIRST, then bulk select to work on specific groups!

### 🔍 Advanced Search

**Enable Advanced Options:**
1. Click the **🔍** button next to search
2. Panel expands with more options

**Advanced Filters:**
- **Regular Expression** - Power search (e.g., `pdf$` for files ending in .pdf)
- **Favorites Only** - Show starred bookmarks
- **Date Range** - Find bookmarks added between dates
- **Usage Range** - Filter by how often you've opened them

**Example Searches:**
- `work.*pdf` - All work-related PDFs (regex)
- `example.com` - All from example.com domain
- `important` - Search tags, notes, and names

### ✏️ Editing Bookmarks

**Quick Edit:**
1. Click **✏️ Edit** button
2. Modal opens with all fields
3. Change:
   - Title/filename
   - Folder
   - Tags (add/remove)
   - Notes
   - Favorite status
4. Click **Save**

**Bulk Edit:**
- Use bulk mode for mass changes
- Best for adding tags or setting folders

### 🌓 Dark Mode

**Quick Toggle:**
- Click the **🌙** icon in header
- Switches between light and dark
- Your choice is saved

**Auto Mode:**
1. Click **⚙️ Settings**
2. Set Theme to "Auto (System)"
3. Follows your system theme

### 📊 Statistics

**View Your Stats:**
1. Click **📊 Stats** button
2. See:
   - Total bookmarks
   - Favorites count
   - Recent activity
   - Total opens
   - Top file types
   - Top domains
   - Popular tags
   - Most used bookmarks

**Use Stats to:**
- Find patterns in your bookmarking
- See which sites you bookmark most
- Discover your most-used tags
- Track your collection growth

### ⚙️ Settings

**Customize Your Experience:**
1. Click **⚙️** icon in header
2. Available settings:
   - **Theme**: Light, Dark, or Auto
   - **Default Sort**: Choose how bookmarks are sorted
   - **Auto-backup**: Enable weekly backups
3. Click **Save**

**Data Management:**
- **Export All Data** - Complete backup
- **Import Data** - Restore or merge

### 📤 Export Options

**Choose Your Format:**
1. Click **📤 Export**
2. Select format:
   - **JSON** - Complete data, can re-import
   - **CSV** - Open in Excel/Sheets
   - **HTML** - Import to browser bookmarks

**Export Selected:**
1. Enable bulk mode
2. Select bookmarks
3. Click **Export Selected**

## 💡 Pro Tips

### Organization Strategy
1. **Use folders for broad categories** (Work, Personal, Learning)
2. **Use tags for cross-cutting themes** (urgent, tutorial, reference)
3. **Star your most important** (top 10-20 bookmarks)
4. **Add notes for context** (why you saved it, what it's for)

### Search Tips
- Start broad, then filter
- Use tags to narrow results
- Try regex for complex patterns
- Combine filters for precision

### Bulk Workflow
1. Filter to show what you want
2. Enable bulk mode
3. Select all visible
4. Perform action
5. Exit bulk mode

### Regular Maintenance
- **Weekly**: Review and tag new bookmarks
- **Monthly**: Check usage stats, organize folders
- **Quarterly**: Export backup, clean duplicates
- **Yearly**: Review and archive old bookmarks

## 🎓 Common Tasks

### "I want to tag all my work PDFs"
1. Filter by File Type: **PDF**
2. Search: `work`
3. Enable **☑️ Bulk** mode
4. Click **Select All**
5. Click **Add Tag** → type "work-docs"

### "Show me my favorite downloads from last month"
1. Click **🔍** (advanced search)
2. Check **Favorites Only**
3. Set **Date From** to last month
4. Done!

### "Export all my learning resources"
1. Click the "learning" tag on any bookmark
2. Or use folder filter if you have a "Learning" folder
3. Click **📤 Export** → **JSON**

### "Find all bookmarks I've never opened"
1. Click **🔍** (advanced search)
2. Set **Usage Max** to `0`
3. Results show unopened bookmarks

### "Organize 50 unsorted bookmarks"
1. Review each bookmark
2. Click **✏️ Edit**
3. Add folder, tags, notes
4. Mark favorites
5. Or use bulk operations for common traits

## 🆘 Troubleshooting

### "My tags aren't showing"
- Click **✏️ Edit** to add tags first
- Tags appear below bookmark title

### "Can't find a bookmark"
- Clear all filters (file type, folder, tags)
- Try searching by domain instead of filename
- Check if regex search is enabled (disable if not needed)

### "Bulk mode stuck"
- Click **☑️ Bulk** again to exit
- Refresh popup if needed

### "Lost my bookmarks!"
- Check your filters - they might be hidden
- Try exporting - if file is large, they're there
- Check different folders in filter

### "Stats not updating"
- Close and reopen popup
- Stats calculate on popup open
